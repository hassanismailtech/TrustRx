# TrustRx Glossary

- **Signal:** a minimum-necessary syndromic report; not a diagnosis or an
  outbreak confirmation.
- **Reporter:** registered CHW, nurse or facility focal person entitled to use a
  defined reporting route.
- **Reviewer:** authorised surveillance actor who records a human decision.
- **Integrity commitment:** a one-way cryptographic value representing a
  protected event/protocol context; it does not reveal the event or establish
  clinical truth.
- **Handoff:** an approved, auditable transfer into an official workflow; never
  an autonomous escalation.
- **Tenant:** the organisation/programme boundary enforced in the application
  and database.
- **Idempotency key:** a bounded request key used to prevent duplicate signal
  creation during transport retries.
- **Delivery receipt:** provider-reported message status; not acceptance,
  verification or response evidence.
