# TrustRx Publication and Evidence Policy

## Repository classification

The TrustRx GitHub repository is currently public. A public repository is a
software-distribution channel, not a diligence room, pilot record, or document
management system. Public content must be safe to disclose indefinitely.

## Permitted in the public repository

- Source code, synthetic fixtures and public API contracts.
- Public-safe architecture and product-boundary documentation.
- Sanitised engineering standards, contributor guidance and release notes.
- Dated, source-linked public regulatory summaries that do not reveal a
  prospective partner, a configuration, a security control gap, or legal advice.
- Public marketing copy only after claim review.

## Controlled outside the public repository

- Named facilities, personnel, partners, funders, interview notes and workflow
  recordings.
- Pilot protocol versions containing participants, locations, contacts or
  operational schedules.
- DPIAs, DPAs, legal advice, security assessments, penetration-test results,
  incident records, risk registers and detailed threat mitigations.
- Budgets, grant applications, investor materials, cap-table material, funder
  pipeline and commercial strategy.
- Credentials, environment inventories, cloud account identifiers, deployment
  logs and any real or pseudonymised health data.

Store controlled material in an access-controlled workspace with named owners,
review dates, retention rules and audit logging. Do not use an ignored folder
inside this repository as a substitute for controlled storage.

## Publication gate

Before a document or artefact is committed, its owner must confirm that it has
no personal data, health data, confidential partner information, credentials,
unpublished vulnerability detail, unsubstantiated performance claim, or
operational information that could enable harm. When in doubt, keep it
controlled and publish a short, sanitised summary instead.

## Current working rule

Uncommitted planning, funding, detailed regulatory, pilot and threat-model
documents remain uncommitted until they have passed this gate or the repository
is intentionally moved to a governed private organisation account.
